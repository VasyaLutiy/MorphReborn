## 3. Приёмка

`<Команда приёмки для каждой области работы. Базовая линия тестов на момент
постановки: N.>`

Обязательные свойства критерия:

- **печатает диагноз.** `assert` без сообщения и `sys.exit(1)` сжигают три
  попытки вслепую (боль 4.1);
- **печатает его ПЛОТНО** — `pytest <путь> -q --tb=line`. Это не косметика, это
  разница между починкой и тремя сожжёнными попытками (см. замер ниже);
- **содержит полный прогон** для карты, которая правит существующий файл
  (правило 3) — иначе регрессия в чужом тесте не видна;
- **проверяется руками до отправки**: команда обязана реально запускаться;
- **автор критерия ≠ автор кода** (правило 2). В колоде это значит: тест
  отдельной картой или в `targets` вместе с кодом, но сформулированный в спеке,
  а не оставленный на усмотрение исполнителя.

### Почему `--tb=line`: замер 18.09

Одно и то же падение (7 упавших фикстур внутри полного прогона на 431 тест),
три формата вывода. Обратная связь уезжает в перегенерацию обрезанной до 4000
символов — голова 1000, хвост ~2950, середина выбрасывается:

| флаги | сырой вывод | после обрезки | полных диагнозов доехало |
|---|---|---|---|
| `-q` | 16818 | 4000 | **1**, и тот погребён в листинге исходника |
| `-q --tb=line` | 4338 | 4000 | **5** |
| `-q --tb=no` | 2941 | 2941 | **0** |

Карта `cli-run-cycle` сожгла все три попытки на одном дефекте: три раза видела
`intent must be one of` и ни разу — список допустимых значений. Ответ лежал в
вырезанной середине.

**Почему голова бесполезна:** её съедает преамбула pytest — по символу на каждый
тест прогона. Сегодня их 431, завтра 600. Отсюда неприятное следствие, которого
никто не проектировал: **чем полнее страж регрессии, тем дальше диагноз от окна
головы.** Плотность формата важнее объёма вывода.

`--tb=no` не использовать: он убирает ровно то, ради чего всё делается.

## 4. Ограничения

1. **Конверт правки существующего файла — 20–60 строк.** Замеры: +11, +27,
   +36, +40, +42, +54. Не влезает — делить карту, а не расширять срез
   (правило 8).
2. **Карта аддитивна.** Удаления — красный флаг. За два прогона: 1 удаление на
   1734 вставки и 2 на 1075.
3. **Код и его тест — одной картой** через `targets`.
4. **Один файл — одна карта-владелец в поколении** (`/deck check` проверяет).
5. **Срез называть явно.** Пустой = весь проект: дорого и даёт `implicit-read`.
6. **Замыкание среза — подсказка, а не правило.** Механическая проверка
   «что импортируют файлы среза» флагает почти всё: на живой колоде она выдала
   9 карт из 9, включая семь прошедших, и дала ложное срабатывание на карте,
   которой `schema.py` был не нужен. Различает не импорт, а **что тесты обязаны
   построить** (см. 2.1). Поэтому список используется как перечень кандидатов
   для автора, а не как гейт:

   ```bash
   # для каждой карты: модули проекта, которые импортируют файлы её среза
   # и в срез не попали — кандидаты, выбирает человек
   venv/bin/python - <<'PY'
   import json, os, re
   for card in json.load(open('.morph/deck.json')):
       meta = card.get('meta', card)
       sl = set(meta.get('context_slice') or [])
       tg = set(meta.get('targets') or [meta.get('target')])
       missing = set()
       for path in sl:
           if not (path.endswith('.py') and os.path.exists(path)):
               continue
           for m in re.finditer(r'^\s*(?:from|import)\s+([A-Za-z_][\w.]*)',
                                open(path, encoding='utf-8').read(), re.M):
               cand = m.group(1).replace('.', '/') + '.py'
               if os.path.exists(cand) and cand not in sl and cand not in tg:
                   missing.add(cand)
       if missing:
           print(card['custom_id'], '->', ', '.join(sorted(missing)))
   PY
   ```
7. **Ширина дешевле глубины.** Каждое поколение — отдельное стояние в очереди
   (~25 мин) **и** прирост контекста оркестратора: колода на 2 поколения шла по
   $0.086 за запрос, на 4 — по $0.127.

## 5. Приёмы, которые уже сработали

- **Чистая логика — в новый файл, в большой файл — только проводка.** Новый файл
  конвертом не ограничен. `flows/morph.py` на 1599 строк получил +40/−1 там, где
  в предыдущей колоде сгорели 14 чужих тестов.
- **Идиому карты брать из реального принятого прогона** (`.morph/runs/*/deck.json`),
  а не из головы.
- **Образец формата — настоящий артефакт**, а не производящий его код: 2.2 КБ
  `report.json` дешевле и точнее, чем `store.py` на 1399 строк.
- **Фикстура домена — копия реального артефакта, а не сочинение.** Если тесту
  нужна морф-карта, дешевле дать ему валидную из `.morph/runs/*/deck.json`, чем
  надеяться, что исполнитель угадает формат. Тогда знание контракта не требуется
  ни из среза, ни из инструкции.

> меряем. Спека, содержащая карты, меряет механику, а не оркестровку.
