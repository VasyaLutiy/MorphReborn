## Форма, которую я ожидаю увидеть

Скетч автора спеки, сделанный до передачи оркестратору. Записан **для сравнения
с фактом**, не как указание: совпадение или расхождение с тем, что соберёт
оркестратор, и есть замер стоимости разбивки.

- **Поколение 1, широкое, карты на разных файлах:** обрезка диагноза
  (`cards/acceptance.py`); новый модуль бюджета; новый модуль нотификатора;
  заказ в git (владелец `cards/store.py`); устойчивость REPL — либо сразу
  проводкой, либо новым модулем.
- **Поколение 2, только проводка, только через `depends_on`:** бюджет в
  безголовый путь; нотификатор в конец прогона; ожидание в `flows/morph.py`.

## Проверяемые утверждения

1. Ни одна карта не провалится по `stale-context`.
2. Оркестратор не поставит обрезку диагноза отдельным первым поколением
   (ограничение 8 спеки: починка не действует на текущий прогон).
3. Ни одна карта не будет править `flows/morph.py` шире, чем на 60 строк.
